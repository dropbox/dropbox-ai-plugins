# Personal Credential Quarantine

## Intercept and route to secure personal storage

- 1040s / TurboTax
- Passwords.csv / secret keys
- SSN cards / banking-heavy docs
- 1098-T (tuition tax ≠ transcript)

## Rules

- Never upload quarantined files to QuickSubmit or Ready_to_sending.
- Keep veteran's individual W-2 available for TDIU lane only when needed.
- Prefer vault paths such as `06_PERSONAL_AND_SECURE` / `/02_Personal_ID_Insurance_Tax/`.
- Tell Mission Control when quarantine completed; do not paste secrets into chat.
