# Dropbox Preflight Fact-Check

## Purpose

Verify doctor names, dates, quotes, and Blue Button pages **before** writing.

## Rules

1. Check the chart note / source document directly (Dropbox/Drive id preferred).
2. Mark each cite: **PASS** / **FAIL** / **OPEN**.
3. Only **PASS** rows reach filings.
4. Never invent exhibits, hours, attacks, exam sites, or Blue Button pages.
5. Trust PDF body dates and sha256 over filenames.

## Output

Table of claims → source path/id → status → note.
